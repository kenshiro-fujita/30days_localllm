# ローカルLLM入門 30日チャレンジ計画

**期間**: 2026年7月14日(火)〜8月12日(水)　※準備日: 7月13日(月)
**投入時間**: 平日1時間 / 土日3時間（祝日 7/20 海の日・8/11 山の日は3時間推奨）
**総学習時間**: 約46時間（祝日を3時間にすれば約50時間）

---

## 30日後のゴール

1. LLMの仕組み（トークン、Transformer、事前学習と事後学習、量子化）を自分の言葉で説明できる
2. マシンスペックと用途に応じてローカルLLMを選定し、Ollama / llama.cpp で運用できる
3. PythonからローカルLLMを呼び出す小さなツールを自作できる
4. **自作データセットでLoRAファインチューニングした「自分専用モデル」がOllamaで動いている**

### スコープの正直な線引き

ゼロからの事前学習（プレトレーニング）は数千GPU時間・数百万円規模の世界なので対象外です。この計画での「LLMを作る」は「**公開モデルを自分のデータで作り変える（ファインチューニング）**」を指します。仕組みの理解は座学と実験でしっかりカバーします。スクラッチ実装に興味が湧いたら、『つくりながら学ぶ！LLM自作入門』（マイナビ出版）が次の一冊です。
