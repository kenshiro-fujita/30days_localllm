# Day 3: 生成パラメータ

## 今日のテーマ

TinySwallowで `temperature` を変え、同じ質問に対する出力の違いを観察する。

## 今日のゴール

- `temperature` の意味を理解する
- `temperature` を低くした場合と高くした場合の違いを見る
- 事実回答、アイデア出し、文章生成で向き不向きが違うことを確認する
- `top_p` の意味をざっくり理解する

## 使ったモデル

```text
hf.co/SakanaAI/TinySwallow-1.5B-Instruct-GGUF:Q5_K_M
```

## temperatureとは

`temperature` は、LLMの出力のランダムさを調整する設定。

```text
temperature 低め = 安定、無難、再現性が高め
temperature 高め = 多様、自由、冒険的
```

ただし、`temperature` はモデルを賢くする設定ではない。

```text
temperatureを下げる = 正確性が保証される
```

ではない。

## Ollamaで使った設定

Ollamaの対話画面で、以下のように設定した。

```text
/set parameter temperature 0.1
```

```text
/set parameter temperature 1.2
```

## 実験1: 事実説明

質問:

```text
ローカルLLMとは何ですか。非エンジニアにも分かるように3行で説明してください。
```

### temperature 0.1

回答:

```text
ローカルLLMは、自分のパソコンやスマホの中に存在するAIのことで、インターネットを使わずに自分自身で動いて質問に答えたり文章を作成したりすることができます。 
まるで家の中にある知能のようなものです！ 😊
ただし、クラウド型(LLM)と比べて処理速度が速く正確なのが特徴です。
```

観察:

- 文章としては自然
- 「自分のPCやスマホの中で動くAI」という説明は大きく外れていない
- ただし「クラウド型と比べて処理速度が速く正確」は言い切りすぎ
- 低temperatureでも正確性が保証されるわけではない

### temperature 1.2

回答:

```text
ローカルLLMは、インターネットなしに自宅のパソコンやスマホの中で動くAIみたいなもので、質問を理解して答えてくれます。
まるで自分のコンピュータの中にある賢い知能みたいですね！ 
バッテリーも使えるし、大容量なので処理が速くて正確です。
```

観察:

- 低temperatureよりもさらに怪しい回答になった
- 「バッテリーも使える」「大容量なので処理が速くて正確」はかなり雑
- 高temperatureでは、自然そうだが根拠の薄い言い回しが増えやすい

## 実験2: アイデア出し

質問:

```text
社内でローカルLLMを活用するアイデアを5つ出してください。
```

### temperature 0.1

回答の概要:

```text
1. チャットボット
2. 翻訳ツール
3. 文章作成支援
4. 顧客対応自動化
5. 社内情報検索システム
```

観察:

- 無難で一般的な回答
- どれもあり得るが、よくあるAI活用案という印象
- 「ローカルLLMならでは」の観点はやや弱い

### temperature 1.2

回答の概要:

```text
1. 質問応答システム
2. 翻訳ツール
3. コード生成
4. 文書要約ツール
5. 顧客対応チャットボット
```

観察:

- 低temperatureより少し攻めた印象
- `コード生成` や `文書要約ツール` が出てきて、少し幅が広がった
- 一方で、「電子メールの一部自動転送」「自席にいるローカルLLM」など、不自然な表現も出た
- アイデア出しではtemperature高めが役立つこともあるが、人間による選別が必要

## 実験3: 文章生成

依頼:

```text
ローカルLLMを学ぶ楽しさについて、note記事の冒頭文を150字程度で書いてください。
```

### temperature 0.1

回答:

```text
ローカルLLMは、まるで魔法使いのように、あなたのパソコンやスマホの中にAIが住んでくれる世界です！ 
インターネットに頼らず、自分の力だけで質問に答えたり文章を作ったりできるなんて、想像以上に楽しいですよ！
これから一緒に学び、その可能性を広げていきましょう。 🌐🧠✨
```

観察:

- 低temperatureでもかなりテンションが高い
- モデル側の文体のクセが出ている
- `temperature` は文体をゼロから変える設定ではない
- モデルの元々のクセやプロンプトの指示も大きく影響する

### temperature 1.2

回答:

```text
ローカルLLMは、インターネットなしに自宅の大切なコンピュータの中で賢く生きるAIたちです。
一緒にその中に入ってみませんか？ 
指示を出すだけで「知恵」を絞って答えてくれますよ！

未知なる冒険が待っています！✨💻🧠
```

観察:

- 表現の幅は広がった
- ただし、比喩が不自然な方向に行った
- 「一緒にその中に入ってみませんか？」は意味がズレている
- 文章生成では、高temperatureにすると表現が崩れることがある

## top_pとは

`top_p` は、次に出すトークン候補の範囲を調整する設定。

ざっくり言うと、以下。

```text
temperature = 候補の選び方の大胆さ
top_p = 候補に入れる範囲の広さ
```

今日は深追いせず、以下の理解にとどめる。

```text
temperature: ランダムさ・冒険度
top_p: 候補として見る範囲
```

## 今日のまとめ

```text
temperatureは、出力のランダムさを調整する。

temperatureを低くすると、回答は無難で一般的になりやすいが、回答の正確性が保証されるわけではない。

temperatureを高くすると、表現の幅は広くなり自由度が高まるが、間違いやズレも増えやすい。

top_pは、次に出すトークン候補の範囲を調整する。
```

## まだ曖昧なこと

- `top_p` を実際に変えると、TinySwallowの回答がどれくらい変わるのか
- `temperature` と `top_p` を同時に変えたときの影響
- どの用途でどの設定値がちょうどよいのか

## 今日の実感

事実説明では、temperatureを高くすると危なそう。

アイデア出しでは、temperatureを高くすると少し幅が出る。ただし、人間が選別する必要がある。

文章生成では、temperatureが高いと比喩やテンションが変な方向に行くことがある。

結局、生成パラメータは「AIを賢くする設定」ではなく、「出力のブレ方を調整する設定」と理解するのがよさそう。
