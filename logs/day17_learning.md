# Day17 学習メモ

## 今日のテーマ

RAGを「検索→文脈注入→回答生成」に分け、Day16のベクトル検索から回答生成へつなげる構成を整理した。

## 今日理解したこと

- ベクトル検索は、質問に意味が近い文章を順位やスコア付きで取得する。
- RAGは、検索で取得した文章と質問をLLMへ渡し、その文章を前提に回答を生成する。
- Day16で実装したEmbeddingとコサイン類似度による検索は、RAGの検索部分に使える。
- 外部知識を更新しながら回答に使うならRAG、回答の傾向や形式、振る舞いを調整するならファインチューニングが基本となる。
- RAGの失敗は、必要な文章を取得できない「検索側」と、取得した文章を正しく使えない「回答生成側」に分けて確認する。

## 今日出てきた重要用語

- RAG：外部データから関連情報を取得し、LLMの回答生成に使う手法
- 文脈注入：検索で取得した文章を、質問と一緒にプロンプトへ入れること
- 外部知識：モデル内部の知識ではなく、回答時に文書などから取得する知識
- ファインチューニング：学習データを使い、モデルの回答傾向や振る舞いを調整すること
