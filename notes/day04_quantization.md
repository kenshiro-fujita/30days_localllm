# Day 4: 量子化の理解

## 量子化とは

量子化とは、モデル内部にある大量のパラメータ(重み付け)の数値(小数)を、より少ないビット数にすることで大まかな値に置き換えて、モデルを軽くする方法です。

量子化してもパラメータの個数そのものは基本的に変わりません。量子化によって各パラメータを記録する細かさを下げることで、ファイルサイズやメモリ使用量を減らせますが、回答品質が低下する可能性があります。

## GGUFと量子化方式
GGUFは、ローカルLLMのモデル本体や、読み込みに必要な情報をまとめて保存・配布するためのファイル形式です。

Q5_K_Mは、モデル内部にあるパラメータの数値を軽量に表現するための量子化方式です。

## TinySwallowで確認した量子化版

| 量子化方式 | ファイルサイズ |
|---|---:|
| Q5_K_M | 1.13 GB |
| Q8_0 | 1.65 GB |

現在使っている量子化方式は `Q5_K_M` です。

`Q5_K_M` は、`Q8_0` よりモデルサイズを小さくしつつ、軽さと回答品質のバランスを取りやすい量子化方式です。

ただし、TinySwallowのQ5とQ8で実際の回答品質を比較したわけではないため、どの程度の差があるかはまだ確認できていません。

## 実行したコマンド

### 保存されているモデルの確認

```bash
ollama list
```

このコマンドで、Ollamaに登録・保存されているモデル名、ID、サイズ、更新時期を確認できる。

### モデルの詳細情報を確認

```bash
ollama show hf.co/SakanaAI/TinySwallow-1.5B-Instruct-GGUF:Q5_K_M
```
このコマンドで分かること：
このコマンドで、モデルのアーキテクチャ（qwen2など）、パラメータ数、モデル設定上のコンテキスト長、Embeddingの次元数(トークンをモデル内部で表す際の次元数)、量子化方式、対応機能、ライセンス情報などを確認できる。
